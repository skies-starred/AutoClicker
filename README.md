# **AutoClicker**

A simple AutoClicker!

## Links

- Discord: https://discord.gg/DB5S3DjQVa

## Commands

- /autoclicker
- /autoclicker config
- /autoclicker toggle
- /autoclicker blockDungeonBreaker
- /autoclicker allowBlockBreaking


- /autoclicker leftClicker
- /autoclicker leftCps [cps]
- /autoclicker leftKeybind [key]


- /autoclicker rightClicker
- /autoclicker rightCps [cps]
- /autoclicker rightKeybind [key]


- /autoclicker whitelist toggle
- /autoclicker whitelist [add|remove] [left|right]
- /autoclicker whitelist clear [left|right]
- /autoclicker whitelist list
